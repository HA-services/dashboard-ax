# Support

- Email: hunain@axsync.com
- Website: https://www.axsync.com
- Apps Store: use the Support tab of the listing.

## What to include in a support request

1. Odoo version and hosting type (Odoo.sh, on premise, other).
2. Module version from Apps.
3. The item or dashboard name and what you expected to see.
4. The text in the item error banner, if any.
5. A screenshot of the item form (Manage, Items).

Typical first reply time is one business day. Bug fixes are free for the life of the listing. Customization requests are quoted separately.
