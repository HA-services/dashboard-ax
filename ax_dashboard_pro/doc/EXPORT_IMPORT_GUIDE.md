# Export and import

## Export an item

Item menu, Export: Excel, CSV, PDF. Canvas charts also export as PNG.

## Export a dashboard

Toolbar, Export. Choose PDF or Excel for a printable or shareable copy, or JSON to move the dashboard to another database.

## Import a dashboard

Manage, Import. Upload a JSON file exported from AXSync Dashboard Pro. Models and fields that do not exist in the target database are reported and the affected items are skipped.

## Templates

Manage, Template library. Save any dashboard as a template, download it as JSON, upload templates from a file. The eight prebuilt templates install with the module.

## File sources

An item can read an Excel (.xlsx) or CSV file uploaded on it. Choose the column to group by and the column to aggregate. Limits: 10 MB, 50,000 rows, 100 columns.
