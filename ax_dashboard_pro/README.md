# AXSync Dashboard Pro

Version 16.0.1.0.0 for Odoo 16. Publisher AXSync, https://www.axsync.com, support hunain@axsync.com. License OPL-1.

AXSync Dashboard Pro lets you build live dashboards on top of any Odoo data without writing code. Pick a model, a measure and a grouping, choose one of 18 item types, drag it into place and share the result. Every item runs with the rights of the user who opens it.

## Highlights

- 18 item types: KPI tile, to-do list, list and 15 chart types.
- Data from Odoo models, formulas, custom read-only SQL, external PostgreSQL or MySQL databases, JSON APIs and uploaded Excel or CSV files.
- 24 date presets with financial year support, %UID and %MYCOMPANY domain tokens, global filters.
- Drag and drop layout on a 12 column grid, resize, copy, move between dashboards, TV mode.
- Eight prebuilt dashboard templates, template library with import and export.
- Drill-down from any chart or tile to the underlying records.
- AI assistant: describe a dashboard in plain words, ask for insights. Bring your own provider.
- Alerts, KPI snapshots, anomaly checks, scheduled email reports.
- Version history with restore, private by default sharing, activity log, performance log.
- Per dashboard menu entries in the Odoo Apps menu.

## Install

See doc/INSTALL_AND_CONFIGURATION.md. Short version: copy `ax_dashboard_pro` into your addons path, update the apps list, install **AXSync Dashboard Pro**.
