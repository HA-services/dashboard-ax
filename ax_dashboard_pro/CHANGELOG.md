# Changelog

## 20.0.1.0.0

First release for Odoo 20.

- Dashboard builder with 18 item types.
- Sources: Odoo model, formula, read-only SQL, external connection, JSON API, Excel or CSV file.
- 24 date presets, financial year start, %UID and %MYCOMPANY tokens.
- Drag and drop grid, TV mode, themes, per dashboard menu entries.
- Eight prebuilt templates, template import and export.
- Why did it change driver analysis, forecast lines, target pacing, alert webhook.
- AI assistant with configurable provider.
- Alerts, KPI snapshots, anomaly checks, scheduled email reports.
- Version history, sharing, activity log, performance log.
- Unit and browser tests included.
